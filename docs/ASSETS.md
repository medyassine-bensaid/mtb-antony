## Re-processing photos

Source files are not stored in the repo. To redo the conversion: put the originals in two folders and run
`python -I tools/optimize-photos.py <ubereats_folder> <googlemaps_folder>` (file names are listed in the script).
To add a single photo by hand: convert to WebP (max 1600 px), save as `public/images/menu/NAME.webp` plus a 240 px `NAME-sm.webp`, then set `image: 'NAME'` on the item in `src/data/menu.ts`.
